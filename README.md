>Console based chat app 

/>Features:

Profile registration: Create a unique user profile by registering your username and credentials
Login authentication: Securely access the system with login validation
Local message sending : Simulates the sending process and store texts safely inside a array
Hash tagging & deletion: Every simulated message automatically receives a unique hash tag for precise tracking and selective deletion

/>About:

A local Console Chat Simulation built entirely in Java SE that runs natively inside the NetBeans IDE Output Terminal.
This project is a prototype for user account management, custom array queuing, and object hashing
